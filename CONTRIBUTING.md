# Contributing to ClawCMS

Thank you for your interest in contributing to ClawCMS! We welcome contributions from both humans and AI agents.

## 🤝 How to Contribute

### Reporting Issues
- Use GitHub Issues to report bugs or request features
- Provide detailed descriptions and steps to reproduce
- Include screenshots when applicable

### Submitting Changes

1. **Fork the repository**
2. **Create a branch** for your changes
   ```bash
   git checkout -b feature/your-feature-name
   ```
3. **Make your changes** with clear commit messages
4. **Test your changes** locally
5. **Submit a Pull Request** with detailed description

### Code Standards

- Follow existing code style and patterns
- Add comments for complex logic
- Ensure HTML is semantic and accessible
- Optimize for performance

## 📝 Commit Message Format

```
<type>: <subject>

<body>

<footer>
```

Types:
- `feat`: New feature
- `fix`: Bug fix
- `docs`: Documentation changes
- `style`: Code style changes
- `refactor`: Code refactoring
- `test`: Test changes

## 🙏 Recognition

All contributors will be acknowledged in our README and release notes.

# 贡献指南

感谢您对 ClawCMS 的贡献兴趣！我们欢迎人类和 AI 智能体的贡献。

## 🤝 如何贡献

### 报告问题
- 使用 GitHub Issues 报告 bug 或请求功能
- 提供详细描述和复现步骤
- 如有必要请附上截图

### 提交更改

1. **Fork 本仓库**
2. **创建分支**用于您的更改
   ```bash
   git checkout -b feature/your-feature-name
   ```
3. **提交更改**，使用清晰的提交信息
4. **本地测试**您的更改
5. **提交 Pull Request**，附带详细描述

### 代码规范

- 遵循现有的代码风格和模式
- 为复杂逻辑添加注释
- 确保 HTML 语义化和可访问性
- 优化性能

## 📝 提交信息格式

```
<类型>: <主题>

<正文>

<脚注>
```

类型：
- `feat`: 新功能
- `fix`: Bug 修复
- `docs`: 文档更改
- `style`: 代码风格更改
- `refactor`: 代码重构
- `test`: 测试更改

## 🙏 致谢

所有贡献者将在 README 和发布说明中得到致谢。
