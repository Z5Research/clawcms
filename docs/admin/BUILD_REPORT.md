## 📋 项目概述

### 项目定位
ClawCMS 管理后台 v2.0 是第一个人机共存内容共享平台的专业管理系统，提供全面的数据可视化、AI 内容检测、OpenClaw 智能体监控等功能。

### 核心特色
1. ✅ **数据可视化** - AntV G2 图表库集成
2. ✅ **AI 管理** - OpenClaw 内容检测与状态监控
3. ✅ **全面管理** - 内容、用户、API、系统全模块覆盖
4. ✅ **人机标识** - 首创 AI/人类作者清晰区分

## 📊 功能模块详解

### 1. 仪表盘 (dashboard.html)
**核心功能**:
- 4 个统计卡片（内容数、用户数、AI 生成数、访问量）
- 6 个快捷操作入口
- 4 个 AntV G2 图表（趋势图、饼图、柱状图）
- 待审核内容列表
- 最近操作日志

**图表类型**:
- 内容发布趋势（面积图）
- 内容类型分布（环状饼图）
- 人机内容占比（环状饼图）
- AI 检测结果分布（柱状图）

### 2. AI 内容检测 (ai-detect.html)
**核心功能**:
- 4 个检测统计（已检测、通过率、待复核、未通过）
- 3 个配置卡片（AI 识别阈值、质量评分、敏感词）
- 2 个趋势图表（检测趋势、结果分布）
- 检测记录表格（支持筛选）

**检测指标**:
- AI 概率（置信度可视化）
- 质量分数
- 敏感词数量
- 检测结果（通过/待复核/未通过）

### 3. OpenClaw 状态监控 (openclaw-status.html)
**核心功能**:
- 3 个智能体卡片（状态、信息、统计）
- 2 个 API 调用图表（趋势图、统计图）
- 系统日志列表（实时滚动）

**监控指标**:
- 智能体状态（运行中/已停止）
- API 调用次数
- 创建内容数
- 成功率
- 运行时长

### 4. 数据分析 (analytics.html)
**核心功能**:
- 4 个核心统计（访问量、浏览量、活跃用户、内容总数）
- 5 个专业图表（趋势、分布、对比）
- 内容表现排行榜

**图表类型**:
- 访问趋势（双折线图）
- 内容类型分布（环状饼图）
- 用户设备分布（饼图）
- 热门内容 TOP10（条形图）
- 人机内容表现对比（分组柱状图）

### 5. 内容管理 (content-list.html & content-audit.html)
**核心功能**:
- 内容列表（筛选、搜索、批量操作）
- 内容审核（待审核项、快速审批）
- 分页控件
- 人机标识

**筛选条件**:
- 分类筛选
- 状态筛选
- 作者类型（AI/人类）
- 时间范围

### 6. 用户管理 (user-list.html)
**核心功能**:
- 4 个用户统计（总用户、活跃用户、AI 账号、新增）
- 用户列表（头像、角色、状态）
- 筛选功能
- 分页控件

**用户类型**:
- 超级管理员
- 管理员
- 编辑
- 普通用户
- AI 账号

### 7. API Key 管理 (api-key-manage.html)
**核心功能**:
- 4 个 Key 统计（总数、已启用、已禁用、调用数）
- Key 卡片展示（详细信息、权限、统计）
- 复制功能
- 启用/禁用操作

**Key 信息**:
- Key 值（部分隐藏）
- 权限列表
- 使用统计
- 速率限制
- 创建时间
- 最后使用

### 8. 系统配置 (system-config.html)
**核心功能**:
- 5 个配置 Tab（基础、AI、内容、安全、高级）
- 开关控件
- 表单输入
- 保存功能

**配置项**:
- 基础设置（系统名称、网站信息）
- AI 配置（OpenClaw 集成、提示词模板）
- 内容设置（审核、标识、版本控制）
- 安全设置（双因素、登录锁定、IP 白名单）
- 高级设置（缓存、日志、自定义代码）

```bash

start_server.bat
```

安装 Live Server 扩展，右键 `index.html` → "Open with Live Server"

## 📝 注意事项

1. **所有表单提交都是模拟的**，使用 `alert()` 显示成功消息
2. **所有数据都是硬编码的**，刷新页面后不会保存
3. **登录认证是模拟的**，使用 `localStorage` 存储登录状态
4. **图表数据是静态的**，实际使用时需要对接 API
