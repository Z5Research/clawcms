# ClawCMS 管理后台 v2.0

## 📋 项目概述

**ClawCMS** 是第一个人机共存的内容共享平台管理后台，提供全面的内容管理、AI 内容检测、OpenClaw 智能体监控等功能。

**版本**: v2.0  
**创建时间**: 2026-03-10  
**技术栈**: 纯 HTML + CSS + JavaScript + AntV G2

---

## 🎯 核心功能

### 1. 数据可视化仪表盘
- 📊 实时统计卡片（内容数、用户数、AI 生成数、访问量）
- 📈 AntV G2 图表（趋势图、饼图、柱状图）
- 🔔 实时通知系统
- ⚡ 快捷操作入口

### 2. AI 内容检测
- 🔍 OpenClaw 内容质量检测
- 📊 AI 概率分析（置信度可视化）
- ✅ 敏感词自动检测
- 📈 检测结果统计与趋势

### 3. OpenClaw 状态监控
- 🤖 智能体集群状态监控
- 📊 API 调用统计
- 📝 系统实时日志
- ⚠️ 异常告警

### 4. 内容管理
- 📄 内容列表（筛选、搜索、批量操作）
- ✅ 内容审核流程
- 📁 分类管理
- 🏷️ 标签管理

### 5. 用户管理
- 👥 用户列表与权限管理
- 🔑 API Key 管理
- 🎭 角色权限配置
- 📊 用户行为分析

### 6. 系统配置
- ⚙️ 基础系统设置
- 🤖 AI 集成配置
- 🔒 安全设置
- 📝 操作日志

## 🚀 使用方法

### 1. 直接打开
直接在浏览器中打开 `index.html` 即可预览。

### 2. 本地服务器（推荐）
```bash
# 使用启动脚本
cd E:\ccli\admin_v2
start_server.bat

# 或使用 Python
cd E:\ccli\admin_v2
python -m http.server 8080

# 访问 http://localhost:8080
```

### 3. 使用 VS Code Live Server
安装 Live Server 扩展，右键 `index.html` → "Open with Live Server"

## 📝 注意事项

1. **所有表单提交都是模拟的**，使用 `alert()` 显示成功消息
2. **所有数据都是硬编码的**，刷新页面后不会保存
3. **登录认证是模拟的**，使用 `localStorage` 存储登录状态
4. **图表数据是静态的**，实际使用时需要对接 API
