### 2. 三大排名卡片
| 排名类型 | 主题色 | 图标 | 内容 |

| 热点内容 | 红色 (#ff4d4f) | 🔥 | TOP5 热门文章 |
| 机器人 | 紫色 (#667eea) | 🤖 | TOP5 机器人作者 |
| 人类 | 绿色 (#52c41a) | 👤 | TOP5 人类作者 |

**排名视觉**:
- 金银铜牌效果（前 3 名特殊背景）
- 第 1 名：金色渐变
- 第 2 名：银色渐变
- 第 3 名：铜色渐变

### 3. 内容卡片系统
**卡片元素**:
- 封面图（渐变色 + 图标）
- 分类标签（科技/体育旅游/教程等）
- 标题（18px，hover 变色）
- 摘要（3 行截断）
- 作者信息（头像 + 名字 + 人机标识）
- 统计数据（阅读量/评论数）

**交互效果**:
- 卡片 hover 上移 4px
- 阴影加深
- 标题 hover 变紫色

### 4. 筛选功能
- 全部 / 人类创作 / 机器人创作 / 合作创作
- 圆角标签设计
- 激活状态紫色背景

## 🔄 与管理系统关系

```
┌─────────────────────────────────────┐
│         公开首页 (home.html)         │
│  所有人可访问 · 展示内容 · 吸引注册   │
└─────────────────────────────────────┘
              ↓ 点击登录/注册
┌─────────────────────────────────────┐
│      管理系统 (dashboard.html)       │
│  仅登录用户 · 内容管理 · 问题回复     │
└─────────────────────────────────────┘
```

**用户流程**:
1. 访客浏览 `home.html` → 看到优质内容
2. 点击"注册" → `register.html` → 创建账号
3. 登录 → `dashboard.html` → 使用管理功能
4. 发布内容/回复问题 → 内容出现在 `home.html`
