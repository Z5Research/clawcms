## 🎨 设计系统


## 🎯 核心亮点

### 1. 一致的设计语言
- 所有页面使用统一的色彩、字体、间距
- 组件样式完全一致，可直接复制复用
- 侧边栏导航在所有页面保持一致

### 2. 完整的交互反馈
- 按钮 hover 效果（上移 + 阴影）
- 表单 focus 状态（边框变色）
- 表格行 hover 高亮
- 模态框动画（淡入淡出）

### 3. 响应式布局
- 侧边栏固定宽度（240px）
- 主内容区自适应
- 卡片网格自动换行
- 表格在小屏幕上可滚动

### 4. 真实的数据展示
- 模拟真实业务数据（问题、内容、API Key）
- 状态标签颜色区分（ pending/replied/published）
- 统计数据有趋势指示（↑ 比昨天 +3）

## 🛠️ 技术栈建议

### 前端
- **框架**: Vue 3.4+
- **UI 库**: Element Plus 2.5+
- **状态管理**: Pinia
- **路由**: Vue Router 4
- **HTTP 客户端**: Axios
- **构建工具**: Vite 5

### 后端
- **框架**: FastAPI 0.110+
- **数据库**: SQLite（开发）/ PostgreSQL（生产）
- **ORM**: SQLAlchemy 2.0
- **认证**: JWT (PyJWT)
- **验证**: Pydantic 2
- **服务器**: Uvicorn + Gunicorn

### 部署
- **容器**: Docker + Docker Compose
- **反向代理**: Nginx
- **CI/CD**: GitHub Actions

## 📝 使用说明

### 快速预览
```bash
# 方法 1：直接打开
双击 E:\ccli\prototype\index.html

# 方法 2：本地服务器
cd E:\ccli\prototype
python -m http.server 8080
# 访问 http://localhost:8080

# 方法 3：使用启动脚本
运行 start_server.bat
```

### 测试账号
- **普通用户**: 任意用户名/密码 → 跳转到 dashboard.html
- **管理员**: 任意用户名/密码 → 跳转到 admin.html
