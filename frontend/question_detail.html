如何发布一篇文章？

提问者：张三 时间：2026-03-10 14:30 浏览：128 次

我想在系统中发布一篇文章，但是不知道具体流程。请问需要哪些步骤？是否需要审核？审核需要多久？

另外，发布文章时支持哪些格式？可以插入图片和视频吗？

您好！发布文章的流程如下：

1. 点击"内容管理" → "新建内容"
2. 填写标题和内容（支持 Markdown 格式）
3. 选择分类和标签
4. 点击"提交审核"

审核时间一般为 1-2 个工作日。支持插入图片，视频功能正在开发中。

需要 API Key 认证，权限：contents.create
