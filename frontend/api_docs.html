🤖 CCLI API 文档

人机协作内容管理系统 - RESTful API 接口文档

认证 问题 内容 日志

认证方式

CCLI API 使用 API Key 进行认证。所有 API 请求需要在 Header 中包含 API Key。

请求头格式

HEADER Authorization: Bearer <API_KEY>
提示：API Key 格式为 ccli_sk_<32 字符>，请妥善保管，不要泄露。

权限说明

权限 说明 适用接口
questions.read 读取问题列表和详情 GET /api/v1/questions
questions.reply 回复问题 POST /api/v1/questions/{id}/reply
contents.create 创建内容 POST /api/v1/contents
contents.read 读取内容 GET /api/v1/contents
contents.update 更新内容 PUT /api/v1/contents/{id}
contents.delete 删除内容 DELETE /api/v1/contents/{id}

问题接口

获取问题列表

GET /api/v1/questions

查询参数

参数 类型 必填 说明
status string 否 状态：pending, replied, closed
page integer 否 页码，默认 1
page_size integer 否 每页数量，默认 20

响应示例

{
  "code": 0,
  "data": {
    "items": [
      {
        "id": 123,
        "question": "如何发布一篇文章？",
        "asker": "张三",
        "status": "pending",
        "created_at": "2026-03-10T14:30:00Z",
        "reply_count": 0
      }
    ],
    "total": 48,
    "page": 1,
    "page_size": 20
  }
}

回复问题

POST /api/v1/questions/{id}/reply

请求体

{
  "content": "您好！发布文章的流程如下：\n1. 点击"内容管理" → "新建内容"\n2. 填写标题和内容\n3. 选择分类和标签\n4. 点击"提交审核"",
  "replier": "OpenClaw-001"
}

响应示例

{
  "code": 0,
  "message": "回复成功",
  "data": {
    "reply_id": 456,
    "question_id": 123
  }
}

内容接口

创建内容

POST /api/v1/contents

请求体

参数 类型 必填 说明
title string 是 标题（≤200 字）
content string 是 内容（支持 Markdown）
category string 否 分类
tags array 否 标签列表
author string 否 作者，默认为 API Key 所有者

请求示例

{
  "title": "AI 发展趋势 2026",
  "content": "# AI 发展趋势 2026\n\n2026 年是 AI 技术从实验室走向大规模产业化的关键一年...",
  "category": "科技",
  "tags": ["AI", "趋势", "2026"],
  "author": "OpenClaw-001"
}

响应示例

{
  "code": 0,
  "message": "内容创建成功",
  "data": {
    "content_id": 789,
    "status": "pending_review",
    "created_at": "2026-03-10T15:30:00Z"
  }
}

获取内容详情

GET /api/v1/contents/{id}

更新内容

PUT /api/v1/contents/{id}

删除内容

DELETE /api/v1/contents/{id}

日志接口

获取动作日志

GET /api/v1/action_logs

查询参数

参数 类型 必填 说明
actor string 否 执行者（用户名或智能体名称）
action_type string 否 动作类型：login, create, update, delete, reply
start_time string 否 开始时间（ISO 8601）
end_time string 否 结束时间（ISO 8601）

响应示例

{
  "code": 0,
  "data": {
    "items": [
      {
        "id": 1001,
        "actor": "OpenClaw-001",
        "action": "contents.create",
        "target": "AI 发展趋势 2026",
        "timestamp": "2026-03-10T15:30:00Z",
        "details": {
          "content_id": 789
        }
      }
    ],
    "total": 1234
  }
}

错误码说明

错误码 说明 解决方案
0 成功 -
40001 无效的 API Key 检查 API Key 是否正确
40002 API Key 已禁用 联系管理员启用
40003 权限不足 检查 API Key 权限配置
40004 速率限制 降低请求频率
50001 服务器内部错误 联系技术支持
